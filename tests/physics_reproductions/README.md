# Original physics reproductions

These scripts were copied from the review's untracked `experiments/e2e_review/winds`
and `turb` folders before implementation. They retain their historical inputs
and assumptions; they are starting-point evidence, not the current test suite.
Current permanent regressions are registered in CMake under `tests/native`, and
per-fix comparisons are in `validation/PHYSICS_BUG_FIX_RESULTS.md`. Generated
arrays, binaries and copied third-party measurements are not packaged here.
